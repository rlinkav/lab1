# lab1

**MedDiary** — это *лёгкое* консольное приложение для ведения и анализа медицинских записей пациентов. 
Поддерживает **фильтрацию по возрасту и полу**, **оценку рисков** и **построение статистики** по диагнозам и показателям.

## Возможности

- Создание заметок о пациентах в формате Markdown
- Фильтрация по возрасту, полу и уровню риска
- Расчёт средних показателей
- Оценка группы риска по настраиваемому порогу
- Топ пациентов с наибольшим риском
- Расчёт корреляций между показателями
- Распределение по диагнозам, возрастным группам и полу
- Экспорт в HTML и PDF
- Тёмная тема

## Установка

1. Установите Python 3.10+
2. Клонируйте репозиторий
3. Установите зависимости

```bash
git clone https://github.com/user/meddiary.git
cd meddiary
pip install -r requirements.txt
```

## Использование
``` bash
meddiary add "Иванов И.И." --age 54 --gender M --diagnosis "Гипертония"
meddiary list --age-from 30 --age-to 60
meddiary analyze --top-n 10 --risk-threshold 0.7
meddiary search "диабет"
```
|**Команда**|**Описание**|
| `add`| Создать заметку |
| `list`| Показать список |
| `search`| Найти по тексту |
| `analyze`|Построить отчет|
